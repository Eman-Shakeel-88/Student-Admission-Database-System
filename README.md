# Student-Admission-Management-System
## About the project
A Student Admission Management Database built using MySQL/MariaDB, XAMPP and phpMyAdmin , featuring five  tables and practical   SQL operations
## Database Tables
1.Students
2.Admission
3.Courses
4.Departments
5.Fees
## SQL Operations practice
. CREATE TABLE-Creating database tables.
. INSERT INTO-Adding new student records.
. UPDATE-Updating student GPA.
. UPDATE-Modifying admission records.
. ORDER BY GPA DESC-Displaying students records in descending GPA order.
. WHERE-Finding records with unpaid fees.
## Technology Used
. MySQL/MariaDB
. XAMPP
. phpMyAdmin
